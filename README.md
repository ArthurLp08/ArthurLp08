## 🚀 Projetos em destaque

### 📝 Corrige-Me

Plataforma de correção de redações do ENEM utilizando Inteligência Artificial.

O projeto nasceu durante minhas aulas de **Gestão de Startups**, com a ideia de transformar um problema real dos estudantes em um produto digital.

**Principais funcionalidades:**

- Correção utilizando IA
- Nota geral e por competência
- Feedback detalhado
- Pontos fortes e pontos de melhoria
- Exemplos práticos
- Histórico de redações
- Acompanhamento da evolução
- Sistema de autenticação

**Stack:**  
`Next.js` `TypeScript` `Tailwind CSS` `shadcn/ui` `Supabase` `Gemini API`

---

### 💰 FinTrack

Dashboard financeiro para gerenciamento e visualização de finanças pessoais.

O projeto foi desenvolvido para praticar a construção de uma aplicação completa, desde a interface até autenticação e persistência de dados.

**Principais funcionalidades:**

- Dashboard financeiro
- Controle de receitas e despesas
- Categorias
- Relatórios
- Metas financeiras
- Histórico de transações
- Autenticação

**Stack:**  
`Next.js` `TypeScript` `Tailwind CSS` `shadcn/ui` `Supabase`
